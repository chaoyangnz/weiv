## Packet 7 — Typed script-fact decoding (2026-11-07)

Implemented ADR-010. Added owned records for props, imports, bindings, diagnostics,
helper dependencies, mutations, aliases and callback registrations. All source
ranges use the shared Span; diagnostic coordinates are checked u32 values.
DecodedScript owns facts separately from emitted JavaScript. String backing may
be shared safely but no returned field borrows the temporary JSON DOM.

The schema layer validates presence before indexing JSON objects and uses typed
errors for invalid JSON, absent fields, wrong shapes, invalid unsigned spellings,
overflow and inverted spans. Required nullable fields, unknown-field tolerance,

the Rust/Zig schema. Deliberate malformed-protocol refinements reject Zig's
numeric string/integral-float coercions and inverted ranges; Cyna's JSON parser
also rejects duplicate keys. Valid backend component behavior is unchanged.

Generic record-array decoding uses checked Cyna callbacks returning T!E. Native
validation confirms this path works for string lists and all owned record types;
it did not require replacing generics with handwritten array loops. The initial
lowering failure was reduced to installed Cyna's top-level string constants,
reported as LG-56. The checked source binary prints the reduced hello example
successfully. Tests use fixture functions while retaining the installed compiler.

Added 17 permanent handwritten decoder tests: complete field coverage, null vs
empty values, malformed/unknown/missing fields, strict unsigned bounds, u32 and
